# 7D6N Kyoto & Osaka Solo Runner's Itinerary Web App
**京阪神 7天6夜 獨旅跑者・跑步驛站・精品冰美式與深度美饌地圖**

這是一個自包含的互動式單頁網站應用程式（Single-Page Web Application），專為熱愛**清晨跑步（~06:30 AM）**、**跑步驛站空手跑服租借（手ぶら）**、**早晨精品冰美式（Iced Americano）** 與 **無動物內臟（Zero Offal）排隊美食** 的獨旅跑者設計。

👉 **[🌐 點此前往 GitHub Pages 線上即時瀏覽（Live Demo）](https://steven1lung.github.io/kyoto-osaka-itinerary/)**

---

## 🌟 網站核心特色與互動功能

- **🎨 京都現代侘寂 / 日系極簡美學**：以暖白背景（`#F9F8F6`）、日式靛藍（`#1E2A38`）與石墨灰呈現，卡片式留白設計，完美適應手機與電腦。
- **⚡ 頂部單頁秒切換（Single-Page Tab Navigation）**：免重新載入即可在 `🌟 總覽 Overview`、`🏃 晨跑名所＆跑步驛站`、`☕ 07:30 冰美式精品地圖`、`🍜 免預約＆零內臟美饌` 與 `📅 Day 1 ~ Day 7` 間切換。
- **🔍 每日行程動態篩選按鈕**：Day 1~7 每日頂部內建互動篩選膠囊（全部 / 晨跑與修復 / 精品咖啡 / 美食 / 景點），附帶動態數量徽章與過濾動畫。
- **📍 實用內行亮點與一鍵 Google Maps 導航**：每一張卡片皆包含營業時間驗證、實用內行指引（如日文點餐聲明語：`Horumon wa taberaremasen`、手ぶら空手套裝租借流程）與獨立 Google Maps 導航按鈕。

## 🛠️ 本地開發與自動化測試

本專案使用原生 HTML5 + Tailwind CSS + Vue 3（CDN 零建置）開發，並附帶 Python 3 自動化測試套件：

```bash
# 啟動本地開發伺服器
python3 -m http.server 8088

# 執行自動化測試 (包含 DOM 渲染、資料完整性與開門時間驗證)
python3 verify_itinerary.py
```
